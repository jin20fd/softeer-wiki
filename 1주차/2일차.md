실질적으로 웹서버 만들기 과제를 수행하기 위한 1주차의 1~3단계 과제를 모두 살펴보고, 1주차 목표와 구현 계획을 수립하였습니다.


## 설계
분리하면 좋을 것 같다고 생각한 클래스와 역할에 따라서 간단한 설계 계획 수립

- RequestData : 요청 객체
- ResponseData : 응답 객체
---
- MessageParser : 요청메시지를 파싱하여 RequestData 객체를 만들어 저장하는 역할
- FileManager : Request 경로에 따라서 File 파일을 찾고 읽어 버퍼를 반환하는 역할
- PathMapper : 요청경로에 따라서 정적 또는 동적 데이터를 처리하도록 매핑해주는 역할
- UserManager : 사용자 정보를 데이터베이스에 저장하고사용자 아이디를 반환하는 역할
- ResponseBuilder : 클라이언트에게 전달할 응답 객체를 만들고 반환하는 역할
