### 작업 과정에서의 배운 점

**302 응답 구현**

- 응답 헤더 `Location` : redirect 3xx 응답 코드에 필수, 201 Created에도 사용 가능
    - 헤더 값은 클라이언트 측에서 절대경로와 상대경로를 모두 지원한다.
    - 상대경로 지원방식 : 이전 요청 메시지 Host 헤더값을 기준으로
    - 201 응답시, 생성된 리소스를 참조할 수 있는 URI를 Location헤더를 작성하는 것이 권장된다.

**응답 헤더들을 responseData 각각의 필드로 vs 헤더는 모두 Map으로**

→ 응답 헤더에 필수 값이 있는가? 필수값은 헤더, 그렇지 않으면 Map으로 관리, 우선은 헤더 값이 많지 않아서 모두 필드로 관리하고 추후에 Map으로 변경할 예정이다

- 응답 메시지에는 Transfer-Encoding이나 Content-Length 헤더가 필수
- body가 존재한다면 Content-Type 헤더가 필수
- 응답 헤더의 값은 문법적으로 비어있을 수 있지만, 권장하지 않는다

**코드 리뷰**

- HashMap의 key로 어떤 객체를 사용할 때는, 그 객체의 equals()와 hashCode()를 오버라이딩 해주어야 한다
- interface에 선언된 메서드는 public을 명시하지 않아도 동일하게 작동한다
- Method 타입 : 자바 리플렉션 API에서 제공하는 클래스, 클래스의 메서드를 동적으로 가지고 있어서 실행 가능하다
- Parameter : 함수 인자의 이름을 키값으로 사용 가능하다

- 코드 리뷰를 통한 학습하기
    
    세연님의 코드를 리뷰하면서 구조를 개선시킬 방법이 무엇인지 고민해보기도 하고, 몰랐던 새로운 문법들도 많이 배우게 되었다.
    

### **Problem**

- 리팩터링에 집중하다보니 성과가 눈에 보이지 않아서 과제에 흥미가 떨어진다
