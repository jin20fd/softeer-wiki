# ⏳ 회고

### **Keep**

- 개발하고자 하는 것을 명확히 하고 문서화하기
    
    예외처리에 대한 명세를 확실히 세우고 그에 대한 코드를 작성하였더니 확실히 빠르게 개발할 수 있었다. 특히 예외처리에 대한 작업을 하다보니 테스트코드가 전하고자 하는 것이 참 명확한 문서인 것 같다는 생각도 하였다. 내일은 오늘의 예외처리에 대한 테스트코드도 직접 작성해볼 예정이다.
    

### **Problem**

- 작은 단위의 작업에 대해 기억을 하지 못한다
    
    그룹세션처럼 작업 내용을 설명해야 하는 시간들이 계속 있는데, 큰 하나의 작업(미션의 주요 요구사항 반영)이 아니라 작은 단위(기존 코드에서 발견한 오류)의 여러 작업을 하면 어떤 작업을 했는지 기억을 잘 하지 못하는 문제가 있었다.
    
    큰 단위의 작업이 아니면 기록을 잘 안했던 것 같다. 그 작업에서 배운 내용이 의미있어도 기록을 잘 하지 않았던 것 같다. 작은 단위의 작업들도 기록하는 습관을 들여야 겠다.
    

- 실수를 많이 한다
    
    HTTP 상태코드 메시지를 잘못 작성한다든가,, 비슷한 이름의 함수를 잘못 호출한다든가 하는 실수를 꽤 많이 한다. 이런 실수가 누적되면 오류를 찾기도 힘들어질 것 같다. PR 올리기 전에는 검토를 하고 제출하도록 해야겠다.
    

### **Try**

- 동료 코드에서 오류 찾아보기
    
    그룹세션을 진행하면서 팀원분들이 내 코드에서 실수한 부분, 오류를 찾아주셔서 도움이 많이되었다. 원래는 코드의 큰 흐름을 위주로 리뷰를 했는데, 앞으로는 동료분들의 코드를 더 꼼꼼히 살펴서 오류를 찾는데에도 도움이 되도록 해야겠다.
