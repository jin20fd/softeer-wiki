## 학습 기록
**[1일차](https://github.com/jin20fd/softeer-wiki/blob/main/2%EC%A3%BC%EC%B0%A8/1%EC%9D%BC%EC%B0%A8.md)**
- HTTP 요청 메시지 파싱 개선 및 테스트 코드 작성
- POST요청 - Body 파싱
- MIME 타입: `application/x-www-form-urlencoded` 학습

**[2일차](https://github.com/jin20fd/softeer-wiki/blob/main/2%EC%A3%BC%EC%B0%A8/2%EC%9D%BC%EC%B0%A8.md)**
- 302 리다이렉트 응답 구현 (`Location` 헤더 이해)  
- Content-Type 자동 처리 구현  
- MessageParser 메서드 분리 및 리팩토링  
- 코드 리뷰 통해 HashMap, 리플렉션 API 활용법 학습

**[3일차](https://github.com/jin20fd/softeer-wiki/blob/main/2%EC%A3%BC%EC%B0%A8/3%EC%9D%BC%EC%B0%A8.md)**
- 쿠키/세션 기반 로그인 구현  
- 세션 ID 생성 전략 고민 (UUID vs SecureRandom 등)  
- 요청경로 - 실행함수 매핑 위한 `BiConsumer`, `Method` 활용  
- JVM 동작 방식 정리

**[4일차](https://github.com/jin20fd/softeer-wiki/blob/main/2%EC%A3%BC%EC%B0%A8/4%EC%9D%BC%EC%B0%A8.md)**
- 로그인/회원가입/로그아웃 예외처리 구현  
- 세션 만료 처리 및 여러 개의 응답 쿠키 처리  
- 회의 통해 프로젝트 기능 기획 반영  

**[5일차](https://github.com/jin20fd/softeer-wiki/blob/main/2%EC%A3%BC%EC%B0%A8/5%EC%9D%BC%EC%B0%A8.md)**
- 2주차 2단계 미션 구현: 동적 HTML (로그인)
- 로그인 사용자만 접근 가능한 페이지 권한 필터 적용 (SessionFilter)
