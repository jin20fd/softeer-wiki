# ⏳ 회고

### **Keep**

- 논의하는 과정을 즐기면서 한 것
    
    배차 알고리즘에 대해서 논의하는 과정에서 서로의 의견을 나누었는데, 의견을 듣고 이야기하는 과정 자체가 즐거웠다. 앞으로도 이렇게 의견을 나누는 과정을 즐기면서 작업을 하고싶다.
    

### **Problem**

- ERD 설계에 대해 논의하는데에 너무 많은 시간이 걸렸다
    
    ERD 설계에 대해 이야기를 나누기 위해서 혼자서도 생각해보아야 할 것들이 많았다. 이야기를 나누다가 또 서로 생각하는 시간을 가지면서 설계를 진행하다보니 오랜시간이 걸렸던 것 같다.
    

### **Try**

- 앞으로 해야할 일들 중 미리 생각하거나 찾아보면 좋을 것들을 미리 정리해보기
    
    앞으로도 API 설계와 같이 논의가 필요할 거리에 대해서 미리 생각을 해보거나, 틈이 나면 API를 미리 찾아서 사용해보거나 해야 겠다.
