### 작업 과정에서의 배운 점

- **구현 기능의 작동 여부를 철저히 검증할 필요성**
    
    이전에 구현했던 페이지 형식의 예약 리스트 조회 기능에서 정렬 조건을 잘못 설정한 사실을, 지수님의 코드 리뷰를 통해 알게 되어 수정했다.
    
    오늘 CD 작업 과정에서도 비슷한 상황이 있었다. GitHub Actions 스크립트는 정상적으로 실행되었지만, CodeDeploy 배포 트리거가 작동하지 않았다. 이를 수정하자 이번에는 deploy.sh 스크립트가 동작하지 않았고, 이후 스크립트 실행은 성공했지만 스프링 서버가 데이터베이스와 연동되지 않는 문제가 발생했다.
    
    이에 따라 GitHub Actions 스크립트에는 CodeDeploy 트리거를 실행하고 배포 상태를 폴링하여 성공 여부를 확인하도록 수정했다. 또한 배포 스크립트에는 set -e 명령어를 추가하여 [deploy.s](http://deploy.sh)h 내의 명령어가 실패하는 경우 에러를 CodeDeploy에서 감지할 수 있도록 하였다. 이렇게 GitHub 이벤트 발생 시 각 배포 단계의 상태를 바로 파악할 수 있도록 개선했다.
    
    이번 경험을 통해 각 단계별 오류를 초기에 파악하지 못하면 작업 시간이 불필요하게 길어질 수 있다는 점을 다시 느꼈다. 앞으로는 기능 구현 이후에도 모든 동작 과정을 철저히 검증하는 습관을 유지해야겠다.
