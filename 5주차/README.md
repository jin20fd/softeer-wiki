## 학습 기록
**[1일차](https://github.com/jin20fd/softeer-wiki/blob/main/5%EC%A3%BC%EC%B0%A8/1%EC%9D%BC%EC%B0%A8.md)**
- AWS 수업 (Access Secret Key, serverless)
- 지도 API 조사 및 선정
- 주간 업무 백로그 작성 및 분담
- Mock 데이터 구축 및 배차 로직 검토


**[2일차](https://github.com/jin20fd/softeer-wiki/blob/main/5%EC%A3%BC%EC%B0%A8/2%EC%9D%BC%EC%B0%A8.md)**
- API 구현 시작
- API 세부 컨벤션(DTO 네이밍, Swagger 등) 결정
- 배차 로직 정리를 위한 회의

**[3일차](https://github.com/jin20fd/softeer-wiki/blob/main/5%EC%A3%BC%EC%B0%A8/3%EC%9D%BC%EC%B0%A8.md)**
- QueryDSL을 활용한 예약 조회 API 구현 (다중 조건 필터링, 페이지네이션)
- 국토교통부 GeoCode API 요청/응답 형식 분석

**[4일차](https://github.com/jin20fd/softeer-wiki/blob/main/5%EC%A3%BC%EC%B0%A8/4%EC%9D%BC%EC%B0%A8.md)**
- CD 파이프라인 구축
  - AWS 권한 설정
  - GithubActions, deploy.sh 스크립트 작성
- 예약 조회 기능 구현(무한 스크롤) 및 오류 수정

**[5일차](https://github.com/jin20fd/softeer-wiki/blob/main/5%EC%A3%BC%EC%B0%A8/5%EC%9D%BC%EC%B0%A8.md)**
- 데모, 스쿼드 세션, 주간 회고 및 피드백 진행
- 국토교통부 API 호출 기능 구현 및 서비스 적용

*주간회고는 최종 프로젝트 팀과 함께 작성하며 팀 위키에 작성
